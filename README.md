NCLEX NGN Practice ModuleThis is an interactive, single-page web application designed to help nursing students practice the NCLEX Next Generation (NGN) Clinical Judgment Measurement Model (NCJMM).The application features a responsive split-screen layout, dynamic unfolding case studies, and an AI integration using the Gemini API to automatically generate new practice scenarios.Features6-Step NCJMM Workflow: Walk through Recognizing Cues, Analyzing Cues, Prioritizing Hypotheses, Generating Solutions, Taking Action, and Evaluating Outcomes.Dynamic Tabbed Chart: Review an unfolding "Nurses' Note", Vital Signs, and Labs on the left panel while answering questions on the right.Instant Feedback & Rationales: Get immediate color-coded visual feedback on "Select All That Apply" questions.AI Case Generator: Input a brief patient scenario, and the app will generate a complete 6-step case study.Educator Tools: Includes a toggleable rationale button for in-class "Knowledge Checks".Fully Responsive: Stacks cleanly on mobile devices and expands to a side-by-side view on desktops.Getting StartedSave the main application code as index.html.Open index.html in any modern web browser to run the application locally.Optional: To use the AI generation feature, you will need to add a valid Gemini API key to the apiKey variable inside the <script> tag of the HTML file.How to Upload This
